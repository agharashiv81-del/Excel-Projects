# Movie Analytics Dashboard

## Project Overview
This Excel dashboard analyzes movie data and provides insights into genres, ratings, runtime, votes, and country distribution.

## KPIs
- Total Movies
- Average Score
- Average Runtime
- Average Votes
- Total Countries

## Features
- Interactive Slicers
- Genre Analysis
- Country Analysis
- Release Year Trends
- Movie Rating Insights

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
